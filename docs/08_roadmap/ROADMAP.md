# Roadmap

## Phase 0: Repository foundation

Goal: Create the file structure, constitution, vision, templates and initial documentation rules.

Exit criteria:

- repository structure exists;
- baseline documents exist;
- templates exist;
- contribution rules exist.

## Phase 1: Manual documentation workflow

Goal: Support humans and AI assistants in creating structured project documents manually.

Exit criteria:

- system and subsystem docs can be created;
- feature and task templates are usable;
- validation templates exist;
- manual audits are possible.

## Phase 2: Audit CLI

Goal: Build a CLI that scans a project and reports documentation gaps.

Exit criteria:

- required files are checked;
- traceability gaps are detected;
- missing validation is reported;
- audit report is generated.

## Phase 3: Context package generator

Goal: Generate bounded context packages for AI agents.

Exit criteria:

- package can be generated by task id;
- mandatory documents are included;
- token budget is estimated;
- final coding prompt is produced.

## Phase 4: Knowledge graph

Goal: Build a graph representation of project knowledge.

Exit criteria:

- nodes and edges are extracted;
- trace paths can be queried;
- orphan tasks are detected;
- dependency map is generated.

## Phase 5: Optional RAG

Goal: Add semantic retrieval as a supplement.

Exit criteria:

- embeddings are generated;
- vector search can suggest optional docs;
- graph-required docs remain mandatory.

## Phase 6: Integrations

Goal: Integrate with tools such as Jira, Confluence, GitHub Actions and AI coding CLIs.

Exit criteria:

- Jira tasks can be generated from task docs;
- Confluence pages can be published from Markdown;
- CI checks documentation quality;
- coding prompts can be passed to CLI agents.
