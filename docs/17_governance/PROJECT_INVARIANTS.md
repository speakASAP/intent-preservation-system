# Project Invariants

completeness_level: complete

status: validated

## Purpose
This document defines the invariant boundaries for the IPS standards repo and keeps the project aligned to truthful standards and governance responsibilities.

## Applicability
This document applies to the repository itself and to any local project code, documentation, or operational flow intentionally owned by the repo.

## Invariants
- Preserve truthful project ownership and avoid fake runtime dependencies.
- Keep the adoption profile aligned with actual standards and governance reality.
- Maintain traceability across goal, task, execution plan, and validation records.
- Prefer explicit `not-applicable` decisions over invented operational claims.

## Exceptions
Any exception must be approved and recorded in the project owner documentation, with an explicit reason and validation evidence.

## Review cadence
This file should be reviewed at project major milestones and before any significant change to the ecosystem standards or validator model.
