# Amendments

## Purpose

This directory holds human-approved amendment proposals for changes that affect
the protected constitution or original vision.

## Rules

- AI agents may draft amendment proposals for human review.
- AI agents must not approve amendments.
- Approved amendments must explain the reason, impact, affected documents and
  validation evidence.
- Protected documents remain unchanged unless the amendment is explicitly
  approved and merged through the controlled review process.

## Template

Use `AMENDMENT_TEMPLATE.md` for new amendment proposals.
