# Local Workflow

## Daily project workflow

1. Review roadmap and current milestone.
2. Select feature.
3. Create or refine tasks.
4. Generate context package for one task.
5. Generate coding prompt.
6. Run AI coding agent.
7. Validate result.
8. Commit code and validation report.
9. Run audit.

## Git workflow

- `main` stores approved state.
- feature branches contain changes.
- protected folders require review.
- every completed implementation must include validation evidence.

## Commit message convention

```text
TASK-001: add required document audit rules
ADR-002: clarify graph-first retrieval
VAL-001: validate audit rules
```
