# Glossary

## Vision

The protected statement of what the project is, why it exists and what success means.

## Constitution

The project laws that define how documentation, AI agents, decisions and validation must behave.

## System

A large functional area of the product that can be reasoned about independently.

## Subsystem

A smaller component inside a system with clear responsibilities and interfaces.

## Feature

A user-visible or system-visible capability that implements part of the product intent.

## Task

A small execution unit that can be completed by one AI agent in one bounded session.

## Context Package

A curated bundle of documents and instructions given to an AI agent for one task.

## ADR

Architecture Decision Record. A document explaining a significant decision, alternatives considered and consequences.

## Validation

A structured check proving that the task, feature, subsystem or system satisfies its criteria and remains aligned with the vision.

## Concept Drift

The difference between the original project intent and the current state of documentation or implementation.

## Source of Truth

The canonical location where project knowledge is stored. In this system, it is the Git repository with Markdown files.
