# Example Project Flow

## Step 1: Write vision

Create protected `VISION.md`.

## Step 2: Decompose systems

Example systems:

- Knowledge Repository
- Audit Engine
- Context Engine
- Prompt Generator
- Validation Engine

## Step 3: Create ADRs

Example decisions:

- Use Markdown and Git.
- Use graph retrieval before RAG.
- Protect vision and constitution.

## Step 4: Create roadmap

Define phases from documentation-only MVP to integrations.

## Step 5: Create tasks

Split features into one-session AI tasks.

## Step 6: Generate context package

For each task, include only the required documents.

## Step 7: Run coding agent

Pass the generated prompt and context package.

## Step 8: Validate

Write validation report and run documentation audit.
